# חיפוש שיירות

אפליקציית ווב אישית לטלפון: מעלים צילום של טבלה, והאפליקציה מזהה את מספרי השיירות (6 ספרות, העמודה הימנית). אחר כך אפשר לחפש מספר ולראות את השורה שלו מתוך הצילום המקורי.

## פרטיות

- הכל רץ בתוך הדפדפן בטלפון. אין שרת ואין ענן.
- זיהוי הטקסט נעשה עם [Tesseract.js](https://github.com/naptha/tesseract.js). קובצי המנוע שמורים במאגר הזה (תיקיית `vendor`), כך שאין פנייה לאתרים חיצוניים.
- בדף מוגדרת מדיניות אבטחה (CSP) שחוסמת בדפדפן כל פנייה לכתובת אחרת.
- התמונות והמספרים נשמרים רק בטלפון (IndexedDB) ונמחקים אוטומטית כשמתחיל יום חדש.
- במאגר יש רק קוד, בלי נתונים.

## שימוש

1. **העלאת תמונות**: אפשר לבחור כמה תמונות בבת אחת. אחרי העיבוד מוצג דוח: ירוק = נשמר, כתום = מספר בן 6 ספרות מחוץ לעמודה הימנית (לא נשמר).
2. **חיפוש**: מקלידים לפחות 3 ספרות ומקבלים את פס השורה ואת תאריך ושעת ההעלאה.
3. **הגדלה**: לחיצה על הפס פותחת מסך מלא עם + / − ואפשרות להציג שורות סמוכות.

## קבצים

| קובץ | תפקיד |
|---|---|
| `index.html`, `style.css` | המסך |
| `app.js` | חיפוש, העלאה, מסך הגדלה, מחיקה יומית |
| `ocr.js` | זיהוי המספרים, בחירת העמודה הימנית וחישוב פס השורה |
| `db.js` | שמירה מקומית ב-IndexedDB |
| `vendor/` | Tesseract.js 7 (רישיון Apache-2.0) ומודל הספרות באנגלית |
